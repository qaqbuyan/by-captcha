# 后端接入示例

本目录包含 Buyan-Captcha 行为验证组件的各类后端接入示例和文档。

## 目录结构

```
demo/
└── lua-waf/    # OpenResty/Nginx Lua WAF 防护模块示例
```

## 各示例说明

### [Lua WAF 防护模块](lua-waf/README.md)

基于 OpenResty/Nginx Lua 的人机验证（CAPTCHA）防护模块，集成 Buyan-Captcha 服务，用于防护恶意自动程序和爬虫攻击。

**适用场景：**
- OpenResty/Nginx 服务器
- Web 应用防火墙（WAF）
- 需要防护恶意爬虫和自动化攻击的场景

**功能特性：**
- 智能人机验证，有效区分人类用户和机器程序
- 多种验证模式（自动显示/无感验证/元素监听触发）
- 验证状态缓存，有效期内免重复验证
- 智能路径排除，支持正则表达式配置
- 响应式验证页面，支持移动端适配
- 多语言支持

## 快速开始

请根据您的服务器环境选择对应的接入示例：

1. **OpenResty/Nginx** → 选择 [lua-waf](lua-waf/README.md)
